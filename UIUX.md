Login Screen
- A visually appealing login screen with a soft gradient background and responsive layout was implemented.
- Input fields have clear labels and spacing, with styling that enhances readability.
- The "Log in" button features hover effects and a loading state, improving user feedback during submission.
- The form is centrally positioned and includes transitions for a smoother experience.

Register Screen
The register screen uses a soft gradient blend distinct from the login screen for variety and user context.
- Fields for name, email, password, and confirm password are clearly labelled.
- Mismatched passwords trigger a styled toast error before submission.
- A responsive design with consistent layout across screen sizes enhances usability.

Logout
- The logout button is styled and fixed in the top-right corner on the dashboard.
- Immediate feedback is given on success or failure with toast notifications.
- Upon successful logout, the user is redirected to the login screen.

Dashboard
- The displayed games in the dashboard are always aligned in a consistent grid pattern
- All text is centered, where at most two fonts are used in the whole page
- All possible features/paths which the user can follow are very clearly visible
- Buttons such as 'Start Game', 'Game Details', 'Create New Game', and 'Log Out' pop out to the user in a  
  consistent color scheme. All buttons have feedback signalling to the user that they can be clicked
- All information is presented in a well layed out, segmented dashboard page that is not confusing or too 
  complex

Edit Game Page
- All questions are clearly visible within the game
- Questions have an edit option that is underlined signalling to the user that it is clickable
- Two salient buttons at the bottom allow users to proceed with the edit or delete the game
- In a different colour, still on theme, is the visible button that takes us back to the dashboard

Edit Question page
- Responsive radio input feilds that will change the layout of the answer section accordingly
- Buttons are different colours that outline different flows that users can follow from the Edit Question 
  page

Starting and Stopping a session
- Users get instant feedback upon starting a game as a game starts to glow in a bright green colour on its 
  boarder signalling that the session is active 
- Clear information is presented on a page for users to interact with such as the buttons that read 'End 
  Game', 'Advance' and 'Session Details'

Player Join 
- When a game is started or 'Session Details' is pressed, a modal pops up, prompting the user to copy the 
  link to the active game. There is also a 'Close' button if the user changes their mind
- This is good UI/UX, as the modal only pops up at the users command for when they want to join a game

Overall
- The whole app as a consistent colour theme, font and layout
