The alternate path test, tests a different user flow than the one described in the happy path. 

The crux of happy path tested:
 - ability to register/login/log out
 - create a game
 - run a session

My alternate path is much more focused on the ability to freely edit and create a game and quesiton, showing all the possibilies. This path expores:
 - Creating and deleting games
 - creating multiple question with multiple question styles
 - editing any aspect of a question such as quesiton style, helper URL, the question itself and the answer
 - deleting a quesiton

The rationale behind this choice is that, as a user, performing actions such as creating, editing and deleteting a game is a large part of what the user will experience. Hence that is why this alternate path focussed mainly on manipulating games/questions so that the user can have a seemless experience.
